# Ontology development instructions

The authoring guide is organized into the [ontology development references](docs/README.md).
Use that index to select the rules for the current task, then follow
[change review](docs/change-review.md).

- [Descriptors](docs/descriptors.md): dimensions, definitions, names, and reuse.
- [Content evidence](docs/content-evidence.md): observable meaning and annotation.
- [Structural relations](docs/structure.md): parts, specialization, and path rules.
- [Other relations](docs/relations.md): constraints, progression, inference, and composition.
- [Annotations and models](docs/annotations-and-models.md): general guidance for content annotations, classification, and embeddings.

[DESIGN.md](DESIGN.md) explains the rationale. [DOCS.md](DOCS.md) covers builds and APIs.
This file remains an entry point for existing links; the rules have one home under `docs/`.
