# Release v0.27.0

Strongly typed Python APIs for released data and caller-supplied ontology snapshots,
with shared data and behavioral tests across Python and TypeScript.

## Changes

- `edugraph.core` provides immutable RDF records, full-IRI descriptor lookup, authored and
  derived relation access, traversal, labeling eligibility, and existing constraint deductions.
  Contexts use isolated indexes for each supplied snapshot and do not load the bundled dataset.
- `edugraph.rdf` adds optional Turtle, TriG, N-Triples, and N-Quads parsing through
  `edugraph-py[rdf]`. It preserves literal lexical forms, RDF term kinds, language/datatype,
  document-scoped blank nodes, graph identity, and source-associated errors.
- `edugraph.generated` exposes released enums and compatibility helpers over the maintained
  Python core. Python algorithm templates have been replaced by ordinary maintained modules.
- Both libraries consume the same authored snapshot and relation contracts. Shared fixtures
  verify navigation, eligibility, and deduction behavior in both implementations.
- Python distributions include public typing information, `py.typed`, original authoring
  references, and generated data. Core and bundled queries have no runtime dependencies;
  only the optional parser requires PyOxigraph.
- Preview package versions now derive from the latest reachable ontology release tag, with
  commit count and SHA. Official TypeScript and Python package versions match the exact tag.

## Compatibility

The authored ontology sources are unchanged from v0.26.0. Ontology validation and assessments
remain TypeScript-only; this release adds no new ontology rule or inference semantics.

Existing Python root imports, enum-module paths, enum values, and definition newline flattening
remain available. Helpers retain list/dict return shapes, but results now have deterministic
full-IRI ordering. Returned collections and legacy relation/definition maps are detached views:
mutating them does not alter subsequent queries. Supply a new snapshot to represent changed data.

Boolean labeling eligibility raises `UnknownDescriptorError` for unknown identifiers. Use
`lookup_descriptor` or the explicit known/unknown result from `inspect_label` for arbitrary input.
Eligibility requires a complete snapshot and does not establish that a descriptor applies to content.
Deduction helpers retain their existing recorded-relation semantics; they are not numerical solvers.

Python 3.11 through 3.14 are supported. See the
[Python API guide](https://github.com/christian-bick/edugraph-ontology/blob/v0.27.0/libraries/python/README.md)
for supplied snapshots, parser installation, typing, and migration details.

## Verification and assets

The implementation passed the local Docker gate, strict typing, 34 Python functional/regression
tests, 16 shared conformance cases, and clean wheel/sdist consumer checks. Preview CI passed on
Linux Python 3.11-3.14 and Windows Python 3.14, alongside the existing TypeScript, ontology,
documentation, browser, and npm package checks. The tagged workflow repeats these gates before
publishing.

Assets include four Turtle sources, combined RDF/XML, `edugraph-ts.tgz` with package version
0.27.0, `edugraph_py-0.27.0-py3-none-any.whl`, and `edugraph_py-0.27.0.tar.gz`.
The Python source distribution can be rebuilt without Node, Jena, or Owlready2.

See the [implementation record](https://github.com/christian-bick/edugraph-ontology/blob/v0.27.0/docs/plan/shared-python-library-implementation.md)
for detailed scope and verification. Deferred performance work and unresolved ontology modeling
questions remain outside this release.
