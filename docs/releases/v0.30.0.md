# Release v0.30.0

This release adds two descriptors and clarifies how several existing descriptors apply to
mathematical tasks. The TypeScript and Python client APIs introduced in v0.29.0 remain unchanged.

## New descriptors

- `CorrectnessEvaluation` is an Ability for judging whether a statement, result, or solution
  satisfies applicable facts, definitions, rules, or task requirements. It specializes
  `Evaluation` and distinguishes exact correctness from plausibility.
- `MultiplesOf5` is a Scope for integer values divisible by 5. It specializes
  `NumericDivisibility` and supports tasks where divisibility by 5 matters independently of
  a sequence's step size.

## Clarified definitions

- `MeasuringTime` includes clock times, calendar dates, and elapsed durations.
- `NumbersLarger*` and `NumbersSmaller*` bound numerical values serving as task inputs or
  results. Digits used to explain place value are not themselves task values.
- `OperandCardinality`, `TwoOperands`, `ThreeOperands`, and `FourOperands` count explicit
  operand occurrences across nested expressions; repeated values count separately.

The numeric bounds retain their inclusive absolute-value endpoints. Existing descriptor
identifiers and structural relations remain unchanged.

The release contains the four authored Turtle sources, compiled RDF/XML, `edugraph-ts.tgz`,
and the Python wheel and source distribution. The tag build verifies the generated clients,
ontology, documentation, and Python compatibility matrix.
