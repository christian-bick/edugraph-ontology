# Release v0.32.0

This release consolidates the mathematics hierarchy and clarifies the boundaries used by
content annotations. The authored ontology contains **1,489 descriptors and 7,934 assertions**,
compared with 1,441 descriptors and 7,668 assertions in v0.31.0. The change comprises
**23 renames, one retirement, and 49 new descriptors**. Assertion counts retain source identity;
the merged RDF graph contains 7,930 unique triples.

## Adoption from v0.31.0

The [dataset adoption handover](v0.32.0-dataset-adoption.md) provides the complete identifier
mapping, changed definitions, labeling eligibility, affected dataset sources, and implementation
acceptance criteria. It is the migration reference for this release; no dataset migration is
claimed by publishing the ontology.

- Replace the 23 former identifiers, including `LineConcept`, `RayConcept`,
  `DecimalPrecission`, `OddAndEvenNumbers`, `MeasuringVolumes`, `IntervalsWithInfinity`,
  `SpatialModelling`, and `NumerationWithIntervals`, using the handover's explicit mapping.
  These are not compatibility aliases.
- The former `ComputationalMathematics` organizer is retired without a replacement label.
- `DivisibilityRules` becomes an organizer and is no longer eligible for direct labeling.
  `FunctionSlope` becomes eligible, with a geometric definition. All rename pairs preserve
  their previous eligibility; 40 of the new descriptors are eligible and nine are organizers.
- Review changed definitions and examples before retaining annotations. In particular,
  distinguish expression-based dependence from numerical functions; collection divisibility
  from performing division; geometric slope from interpreted rates of change; circular solids
  from their right and oblique forms; and intervals from enumerating numbers.
- Recompute derived relations and matching against the new snapshot. New specialization
  paths change inherited claims; `partOf` membership does not establish specialization.
  Existing `Iteration` and `IteratedOperation` identifiers and meanings are retained.

## Family consolidation

- **Algebra and analysis:** generic operation properties and arithmetic-law specializations;
  a coherent linear-systems family; expression dependence names; algebraic rewriting and
  identity subfamilies; function structure, interpretation and discontinuity families.
- **Arithmetic and intuitive mathematics:** percentage-rate determination and application;
  consistent decimal-strategy membership; clarified fraction strategies; collection
  divisibility separated from division; and an interval family under number sense.
- **Formal mathematics, geometry and graph theory:** notation and set fundamentals;
  geometric foundations and one-dimensional objects; right/oblique circular cone and cylinder
  specializations; foundational graph families; and targeted specialization corrections.
- **Number systems, probability and statistics:** a complex-number foundations organizer,
  a focused Markov-chain absorption organizer, central-tendency measures, and a shared
  statistical-inference family.

The [design decision history](../history/2026-10-hierarchy-design-decisions.md) records
alternatives and final decisions by structural family, including accepted no-change decisions
and proposals parked until an actual defect is demonstrated.

## Documentation and remaining limits

The consolidation working notes and all other files formerly in `docs/plan` are removed.
The [working-plan archive](../history/2026-10-working-plan-archive.md) preserves the status of
unfinished boundary, curriculum, validation-performance and consumer work. Their removal does
not mean those issues were resolved. In particular, the recorded unit-fraction, decimal and
fraction Scope boundary inconsistencies remain outside this consolidation release.

## Libraries and release assets

Public TypeScript and Python query APIs are unchanged. Generated identifiers, descriptor text,
and relations reflect the new ontology. RDF/XML is generated freshly from the four authored
Turtle files and is no longer maintained as a checked-in root artifact.

The eight release assets are the four Turtle sources, generated RDF/XML, `edugraph-ts.tgz`,
the Python wheel, and the Python source distribution. The release gate runs the Docker build,
ontology and documentation checks, generated-client tests, packaged-consumer checks, and
Python compatibility tests across supported versions and platforms.
