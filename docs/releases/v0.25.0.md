# Release v0.25.0

Additive release following v0.24.2.

## Changes

Add 20 Scopes describing the justification context of learning content:

- One organizational root: `JustificationScope`.
- Four families through `partOf`: `ProofMethod`, `EvidenceBasis`, `EvidenceCoverage`,
  and `ErrorControl`.
- Fifteen specific members through `specializes`:
  - Proof methods: `DirectProof`, `ProofByConstruction`, `ProofByContraposition`,
    `ProofByContradiction`, `ProofByCases`, `ProofByInduction`, and
    `DisproofByCounterexample`.
  - Evidence bases: `ConstructedCaseEvidence`, `ObservedDataEvidence`,
    `SimulationEvidence`, and `ComputedEvidence`.
  - Case coverage: `SelectedCaseEvidence` and `ExhaustiveCaseEvidence`.
  - Error control: `DeterministicErrorBound` and `ProbabilisticErrorBound`.

Each descriptor includes a definition and explanatory examples or boundaries.
[Justification Scopes](../justification.md) explains their composition and distinction from Areas
and Abilities. [ONT-E6](../content-evidence.md#ont-e6--identify-the-observable-role-of-justification)
requires the context to be supplied or clearly required by the content, rather than merely possible.

## Compatibility

No existing descriptor, definition, structural edge, constraint, or progression relation changes.
No schema or generated-client API implementation changes are needed. The new families add
19 structural edges, with inverse and superproperty access provided by the existing generators.
There are no new cross-family implications, contradictions, or progression assertions.

Existing annotations and their relation closures retain their meaning. Consumers can update
their vocabulary to use the new Scopes; no automatic relabeling is prescribed.
