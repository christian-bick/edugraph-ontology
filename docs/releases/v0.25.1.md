# Release v0.25.1

Patch release following v0.25.0.

## Changes

Use `integrates` for the defining angle concept of four shapes:

- `AcuteTriangle integrates AcuteAngle`: remove the additional `expands` assertion.
- `ObtuseTriangle integrates ObtuseAngle`: remove the additional `expands` assertion.
- `RightTriangle integrates RightAngle`: replace `expands` with `integrates`.
- `Rectangle integrates RightAngle`: replace `expands` with `integrates`.

The angle concept supplies a criterion for defining and identifying each shape category.
The structural specialization relationships remain unchanged.

Keep `NanometerScale translates MeterScale` and remove the explicit `integrates` assertion.
The same length can be represented in either unit. The schema already derives `integrates`
from `translates`, as it does for the other metric-distance unit translations.

The authoring contract in [ONT-R1](../relations.md#ont-r1--declare-specific-relations-and-use-their-inverses)
uses primary relations only and at most one relation per family for a directed pair.
The [check inventory](../plan/automated-rule-checks.md) separates planned automated enforcement
from existing build checks and library regressions.

## Compatibility

No descriptor is added, removed, renamed, or redefined. Schema properties, client API signatures,
structural relations, specialization inheritance, and logical constraints remain unchanged.

The four shape-to-angle links no longer appear in `expands` / `expandedBy` access. `integrates`
is not a subproperty of `expands`, so this is a change in the chosen progression relationship,
not merely redundant-source cleanup. `RightTriangle` and `Rectangle` gain corresponding
`integrates` / `integratedBy` access. Consumers of these progression maps and their closures
should refresh derived results. The combined progression adjacency is unchanged.

The nanometer cleanup preserves generated relation access, including `integrates` and
`integratedBy`, through the existing subproperty handling. Direct annotations and structural
label eligibility do not change. No downstream package pin is updated by this release.
