# Release v0.24.0

Release candidate prepared on 2026-09-10, following v0.23.0.

## Changes

- Add `Scope.SixthFractions` for fractions with denominator six. It specializes
  `CommonDenominator` and expands `ThirdFractions`.
- Leave `CompetencyDescription` composition open by removing its three
  `owl:equivalentClass` descriptor-presence restrictions. It remains a subclass of
  `CompetencyEntity`; applications determine their own completeness requirements.
- Consolidate ontology authoring guidance into [focused references](../README.md)
  with stable rule IDs, content evidence guidance, and explicit inference boundaries.
- Clarify design rationale, literature comparisons, and the interpretation of
  annotations and models across ontology versions.

## Compatibility and review

Existing descriptor identifiers and client helper signatures remain unchanged.
The new scope is available in both generated clients. Consumers relying on the removed
OWL equivalences must review classification or validation assumptions; see
[ONT-R5](../relations.md#ont-r5--compose-competency-descriptions-with-involves).

Release review corrected the new upstream `SixthFractions partOf CommonDenominator`
edge to `specializes`, consistent with `ThirdFractions`, `QuarterFractions`, and
`EighthFractions`. Comparing `1/6` and `5/6` illustrates the sixth-fraction context;
comparing `1/3` and `2/3` has a common denominator without being sixth fractions.
The original edge returned from specialization to composition and mixed child roles
under `CommonDenominator`, contrary to
[ONT-S4](../structure.md#ont-s4--composition-may-lead-into-specialization) and
[ONT-S5](../structure.md#ont-s5--review-the-entire-affected-structure).
Specialization preserves the shared denominator meaning under
[ONT-S2](../structure.md#ont-s2--specializes-preserves-the-broader-meaning).
Both client suites now cover the inherited `RelatedFractions` context, inverse access,
absence of the former `partOf` edge, and the retained progression edge.

## Validation

- Jena 5.6.0 validated all four Turtle sources and generated the combined RDF/XML.
- Both source generators ran successfully. TypeScript compilation and its relation
  suite passed; all 12 Python relation tests passed.
- Both suites also passed against the extracted release tarball and Python wheel.
- Export inspection confirmed that `CompetencyDescription` retains its superclass
  and has no equivalence restrictions. The affected `SixthFractions` ancestor paths
  are acyclic and respect ONT-S4; `CommonDenominator` has no mixed child roles.
- All eight assets were built, archive contents and package versions were checked,
  and SHA-256 checksums were recorded locally under `dist/release-v0.24.0/`.

The documented Docker build was attempted, but its engine did not respond; the build
client was stopped after the bounded wait. The successful fallback used Jena 5.6.0
and the repository's generators, manifests, and tests on Windows with Java 26.0.1,
Python 3.13.4, and Node.js 24.19.0 (the Dockerfile uses Java 21 and Node.js 20).
It validates the candidate artifacts, but does not establish that the Docker pipeline
passes. A successful Docker/CI build of this candidate remains a publication check.

The [existing consolidation work](../plan/ontology-consolidation.md) remains open:
measurement-family definitions, numeric boundary semantics, progression inference,
and a centralized semantic validator. Client tests do not establish complete ontology
rule compliance; see [ONT-W3](../change-review.md#ont-w3--verify-and-report-the-actual-change).

## Publication

Package versions are injected during the build; source package manifests retain their
`0.0.0` placeholders. Publishing the `v0.24.0` tag triggers the
[release workflow](../../.github/workflows/release.yml), which builds and uploads four
Turtle sources, the combined RDF/XML ontology, the TypeScript tarball, and Python wheel
and source distribution. Release preparation does not publish these assets.
