# Release v0.29.0

Both client libraries can now construct a competency involvement statement from a descriptor's
label, definition, and optional comment.

## Combined statements

- TypeScript: `involvementStatement(Scope.IntegerNumbers)`.
- Python: `involvement_statement(Scope.IntegerNumbers)`.
- Both helpers are available from the root and `generated` entry points, and as methods on
  supplied-snapshot contexts.

The default output is:

```text
Involves Integer Numbers: Numbers with no fractional part, whether negative, zero, or positive. For example: -3, 0, 1, 10, and 1345. The value 2 remains an integer when written as 2.0.
```

Callers can override the label, omit comments, or replace the comment introduction. Missing
comments produce no example marker. The helper uses an authored label when available and
otherwise humanizes the IRI local name. It normalizes whitespace and terminal punctuation
while retaining mathematical symbols and letter case.

Text selection is deterministic: use the lexically first nonempty normalized literal for
each annotation. This is not language negotiation. Unknown descriptors, missing definitions,
and explicitly empty labels raise errors instead of producing incomplete statements.
Comments can contain explanation; use an empty comment introduction to append that prose directly.

See the [API contract and options](https://github.com/christian-bick/edugraph-ontology/blob/v0.29.0/DOCS.md#68-combined-descriptor-statements).

## Compatibility and verification

Ontology sources, descriptor identifiers, definitions, relation queries, and existing definition
helpers are unchanged from v0.28.0. The new helpers format text; they do not infer involvement,
content evidence, or labeling eligibility. Core queries remain independent of bundled data
and optional RDF parsers. Python remains supported on 3.11–3.14.

Verification includes shared TypeScript/Python statement cases, snapshot isolation, literal
handling, bundled/root exports, installed-package typing and runtime checks, and the full
Docker gate. The tagged workflow repeats those checks and the Linux/Windows Python matrix.

Assets include the four Turtle sources, combined RDF/XML, `edugraph-ts.tgz` with version
0.29.0, `edugraph_py-0.29.0-py3-none-any.whl`, and `edugraph_py-0.29.0.tar.gz`.
